# 中学英語 全単語データの作り方（共通仕様）

目的：英単語アプリ「Say What?!」（日本人学習者が英語を見てすぐ意味を言えるようにする）に、日本の中学校卒業までに習う英単語（小学校で習う約600〜700語＋中学校の約1,600〜1,800語、合計約2,200〜2,500語。2021年度以降の学習指導要領、New Horizon / Sunshine / New Crown など主要教科書の巻末単語リストを基準）を「全部」入れる。

## あなたの担当
指定されたアルファベットで始まる単語「だけ」を、漏れなく作る。
- 対象：小学校〜中3で習う単語すべて。内容語（名詞・動詞・形容詞・副詞）だけでなく、機能語（前置詞・接続詞・代名詞・助動詞・冠詞・疑問詞）、数詞（序数含む）、曜日・月・季節、国名・言語名の一般的なもの（Japan, English など）も含める。
- 熟語は入れない（1語の単語のみ。ただし don't のような短縮形は不要）。
- 既存の単語は除外：/tmp/claude-0/-home-user-Answer-/7b95110d-ba08-5cac-b5c8-030a513b1d3f/scratchpad/jhs/existing_words.txt に載っている語は作らない（小文字で比較）。
- 不規則動詞の過去形（went, saw など）は別の見出し語にしない。

## 出力
ファイル /tmp/claude-0/-home-user-Answer-/7b95110d-ba08-5cac-b5c8-030a513b1d3f/scratchpad/jhs/out_<担当名>.jsonl に、1行1語の JSON：
{"w":"although","m":"〜だけれども","pos":"接","g":3,"c":"kaiwa","e":"Although it was raining, we played soccer.","j":"雨が降っていたけれど、私たちはサッカーをした。"}

- w：見出し語（小文字。I や曜日・月・国名などは大文字始まり）
- m：日本語の意味。中学生が答える主な意味を1〜2個、15字以内（例「〜だけれども」「借りる」「重要な・大切な」）。品詞で意味が分かれる語は主なものを「・」でつなぐ。
- pos：品詞（名・動・形・副・前・接・代・助・冠・疑・数・間）
- g：初めて習う学年。0=小学校、1=中1、2=中2、3=中3（迷ったら教科書の初出に近い方）
- c：カテゴリ。次のどれか1つ（意味が一番近いもの。機能語・抽象語は kaiwa か yousu か ugoki）：
  kurashi(食べ物・場所・時間・家・家族・日用品) kaiwa(会話でよく使う語・機能語・抽象語) ugoki(動詞・動き) yousu(気持ち・様子・形容詞) doubutsu(動物) umi(海・ビーチ) kuukou(空港・旅) geinou(映画・テクノロジー・メディア) kaimono(買い物・お金) shizen(自然・景色・環境) supotsu(スポーツ) taberu(食事・料理) ongaku(音楽・芸術) asobi(遊び・おでかけ・趣味) tenki(天気・季節) karada(体・健康・病気) gakkou(学校・勉強・歴史・社会・仕事) machi(街・建物・乗り物・ホテル)
- e：自然な英語の例文。その単語の一番よくある使い方。12語以内、中学レベルの文法、アメリカでの生活・旅行・学校の話題が望ましい。見出し語をそのままの形か活用形で1回含める。
- j：例文の自然な日本語訳。

## 品質チェック（必ず実行）
- 書き終えたら python3 で全行を JSON として読み込めるか、w の重複・既存語との重複がないか、c が上のリストにあるか、g が0〜3か、e に w（または活用形）が入っているかを確認し、問題を直す。
- 担当範囲で、教科書に出てくる語の漏れがないか、自分で頭文字ごとに見直す（特に機能語・基本動詞・抽象名詞）。
