# 会話モードの検証（シミュレーション）

仮想の学習者150人に90日間、1日1セット使ってもらい、14日あけて「何も見ずに質問を言えるか」を測った記録。
実在の学習者での実験ではなく、研究で分かっている記憶の性質から作ったモデルによる予測。

| ファイル | 内容 |
|---|---|
| sim.py / sim2.py | 第1回：今の方式 vs 段階ヒントなど、感度分析 |
| sim_linguist.py / sim_round2.py | 言語学者：疑問文の規則・定型句の転移を入れたモデル |
| sim_polyglot.py / sim_polyglot_r2.py (+pg_*.py) | 8ヶ国語マスター：発話回数・即答・音声認識の誤判定を入れたモデル |
| sim_translator.py / sim_translator2.py | 翻訳者：日本語のあいまいさ・別解の扱いを入れたモデル |
| translator_judge.py / judge_rules.json | 別解・音声認識の表記ゆれの判定ルール |
| qitems_v2.json | 97問の書き換え・相手/丁寧さ・キーワード・別解データ |
| round2_design.md | 第2回会議の統合案 |

## 結論（3つのモデルで一致したもの）
- 相手の答えは最初に見せない。ヒントは押した分だけ。
- 4択の返事ターン → 「この返事を引き出す質問を声で言う」ターン（最大の効果）。
- 別解を正解にする判定と、あいまいな日本語の書き換え（無いと答えを隠す効果が消える）。
- 1問10秒以内で声に出す回数を増やす（15秒を超えると効果がなくなる）。
- 効果が出なかったもの：2回まねる、細かいヒント順、新出の順番、文字入力。音声認識は補助のみ（単独で×にすると逆効果）。
